# API

API предоставляет доступ к функциям сервиса гибридной фильтрации спама, управления персональным белым списком и контроля статусов писем.

## Основные операции

- `POST /classifications` — выполнить классификацию и фильтрацию входящего письма;
- `GET /classifications/{id}` — получить результат проверки по уникальному идентификатору;
- `POST /whitelist` — добавить адрес отправителя в белый список с автоматическим восстановлением писем.

## Спецификация

Полное описание API находится в файле `openapi.yaml`.
