# Data Sheet

## Общая информация

**Название датасета:**  
`prithivMLmods/Spam-Text-Detect-Analysis`

**Источник:**  
[Hugging Face Datasets — prithivMLmods/Spam-Text-Detect-Analysis](https://huggingface.co/datasets/prithivMLmods/Spam-Text-Detect-Analysis)

**Назначение:**  
Обучение и оценка моделей бинарной классификации текста для обнаружения спама и фишинговых сообщений в электронной почте и мессенджерах.

## Состав данных

**Объём:**  
Около 5.57 тыс. записей (приблизительно 5,570 строк данных).

**Тип данных:**  
Текстовые данные (строки), размеченные по классам спама.

**Основные поля / признаки:**  
- Текст сообщения / письма (`text` / `message`).
- Метка класса (`label` / `target` — бинарная разметка: спам / легитимное сообщение).

## Получение данных

Данные были собраны, очищены и агрегированы автором (`prithivMLmods`) из открытых источников и репозиториев публичных датасетов для задач обнаружения спама.

## Предобработка

Приведение текста к нижнему регистру (`uncased`), очистка от явных артефактов разметки, токенизация под стандартные архитектуры семейства BERT.

## Ограничения

1. Относительно небольшой объем датасета (~5.5 тыс. примеров) по сравнению с гигантскими корпоративными корпусами.
2. Основная часть текстов ориентирована на английский язык.

## Использование в проекте

Этот датасет является ключевым источником, на котором обучались веса модели `prithivMLmods/Spam-Bert-Uncased`. В нашем ИИ-проекте он определяет базовые возможности модели по распознаванию спам-паттернов, которые интегрированы в наш почтовый сервис через эндпоинт `POST /classifications`.
