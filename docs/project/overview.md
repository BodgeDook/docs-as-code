# Система определения спама

Сервис проверяет входящие письма по персональному белому списку адресатов, а при его отсутствии анализирует содержимое с помощью ML-модели, отправляя спам в корзину с уведомлением пользователя и возможностью гибкого управления ошибочно отфильтрованными письмами.

## Основные пользователи:
- владелец почтового ящика;
- системный администратор / разработчик сервиса.

## Основные функции:
- гибридная фильтрация входящей почты: первоочередная проверка адресата по персональному белому списку, и только при его отсутствии — анализ содержимого сообщения с помощью ML-модели;
- автоматическое перемещение писем, признанных спамом, в корзину с отправкой интерактивного уведомления владельцу почты (с указанием адреса и темы);
- быстрые действия в уведомлении: поддержка трёх вариантов реакций на заблокированное письмо («Оставить в корзине», «Восстановить разово» и «Добавить адрес в белый список»);
- управление белым списком и массовое восстановление: внесение надежного адресата в исключения через уведомление или интерфейс с автоматическим поиском и восстановлением всех его писем из корзины;
- интеграция с почтовым сервером: бесшовное подключение к почтовому ящику пользователя по протоколам/API (IMAP/OAuth) для синхронизации статусов писем и папок;
- просмотр и управление корзиной через интерфейс: централизованный просмотр всех отфильтрованных сообщений, истории срабатываний и настроек фильтрации через приложение.

## Комплект документации:

1. **Описание проекта** — предназначен для всех участников команды и стейкхолдеров для понимания целей, возможностей и ключевого функционала системы.
2. **Требования** — предназначен для системных аналитиков и разработчиков для фиксации функциональных и нефункциональных требований к сервису.
3. **Архитектура системы** — предназначен для архитекторов и бэкенд-разработчиков для описания взаимодействия сервиса фильтрации, почтового сервера, базы данных и ML-модуля.
4. **Документация API** — предназначена для интеграторов и разработчиков клиентских приложений (веб-интерфейса) для корректного взаимодействия с серверной частью системы.
5. **Документация ML-модели** — предназначена для Data Science специалистов и ML-инженеров для описания процессов подготовки данных, обучения, метрик качества и обновления модели классификации спама.
6. **Руководство пользователя** — предназначено для конечных пользователей почтового сервиса для ознакомления с правилами работы фильтра, настройкой белого списка и восстановлением писем.
